# Grouping devices by room

Devices are grouped by room so that a command such as "turn off the kitchen" reaches every device in that room. To set a room, name the device and the room, and the assistant adds it. A device can be in only one room. Renaming a room changes the name for every device in it. Devices that are not in a room are listed separately, and the assistant asks you to assign them before a room command can include them.
