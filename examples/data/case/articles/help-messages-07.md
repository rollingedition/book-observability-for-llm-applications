# Keeping messages in folders

Folders group messages by topic, such as work, travel or family. To move a message, name the message and the folder. The assistant moves it and confirms the move. A message can be in only one folder at a time. Creating a folder is quick: give it a name, and it appears at once. Deleting a folder does not delete its messages; they move back to the main inbox. Folder names must be unique, and the assistant tells you if a name is already taken.
