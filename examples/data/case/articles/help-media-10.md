# Choosing a game or a quiz

The assistant can start a game or a quiz from a short list it knows. Ask for a game by name, or ask for a quiz on a subject, such as geography or history. A quiz asks one question at a time and tells you whether the answer was right. Games that need two players wait for the second player to join before they start. To stop a game, say so, and the assistant reports the score. Some games need a device that supports them; the assistant says if the device cannot run the game.
