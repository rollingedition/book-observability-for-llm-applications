# Sending a message to a group

To send one message to several people, name each person or name a group you have already saved. The assistant lists everyone who will receive the message and waits for your confirmation. A person who is on the list twice receives the message once. If one name cannot be found, the assistant sends to the others and tells you which name was left out. Groups are saved in your contact book, and changing a group changes it for later messages only, never for a message already sent.
