# When a contact is not found

A search can return no match. The usual causes are a misspelled name, a name stored under a nickname, or a contact that was deleted. Try the full name, or a name the person is known by. If no contact is found, the assistant can add a new one: give the name and the address, and the assistant confirms before it saves them. The assistant never guesses an address. If the contact book itself cannot be reached, the assistant says so and does not send anything in its place. Try again later, or add the contact in your contact book directly.
