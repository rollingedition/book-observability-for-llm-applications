# Listening to a radio station

A radio station plays a live stream, so it has no end and no skip. Name the station, or the kind of station you want, such as a news station or a station that plays jazz. The assistant reports the station's name when it starts. Stations are found by name or by frequency. If a station is not available in your area, the assistant says so and suggests a station that is. Stopping a station stops the stream; it does not record it.
